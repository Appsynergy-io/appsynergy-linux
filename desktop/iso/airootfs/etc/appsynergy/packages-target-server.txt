# window. It is a 2 MB package standing between a working cutover and a dead

# Dependency of appsynergy-linux-headers, listed here on purpose.
# The kernel packages are installed with `pacman -U` from local files, and
# pahole is the one thing that transaction has to fetch from a repo. pacman 7
# sandboxes downloads with Landlock + the `alpm` user, and OVH's rescue kernel
# has no Landlock (`/sys/kernel/security/lsm` = `capability` only) — so that
# fetch dies with "restricting filesystem access failed" and takes the install
# with it. pacstrap runs under the Arch bootstrap's own pacman.conf, which
# permits the download, so pulling pahole in here leaves the later `pacman -U`
# with nothing to retrieve and no sandbox to set up.
pahole
